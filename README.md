# Borozdov Marker

A theme from the Borozdov collection. Two faces — light **Sketchbook**, cream paper and a
black marker, and dark **Blackboard**, chalk-white strokes on black. Ink outlines on
everything, white cards, square corners and one pink coin for what sells.

![Borozdov Marker in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/marker/main/screenshots/light.png)

![Borozdov Marker in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/marker/main/screenshots/dark.png)

## Principles

- **Drawn with a marker.** Every box — buttons, fields, callouts, code, tables, tags — has
  a 1px ink outline and square 4px corners; nothing casts a shadow.
- **Colour as stickers.** A pink coin fills what you tick or switch and the selected
  file; a yellow marker highlights; the main button is solid ink. Links are ink with an
  underline and light up pink on hover.
- **One geometric sans.** Inter for everything, tracked tight as it grows; headings at
  500, so bold still reads as bold.
- **Two faces of the same page.** Sketchbook is cream with black strokes; Blackboard
  flips them to white strokes on black.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as marker boxes: an ink outline, a light wash of the type's colour
- Tags as outlined stickers that turn pink on hover
- Code and tables in ruled boxes; embeds and images with a soft 16px edge
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Marker**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/marker/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Marker/`, then choose Borozdov Marker under
Settings → Appearance → Themes.
